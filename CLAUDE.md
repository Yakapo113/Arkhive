# Arkhive (arkhive.us)

Static site served from this repo (GitHub Pages, `CNAME` → arkhive.us). Each tool lives in its own folder as a single `index.html`.

## Always pull first

This repo is edited from two machines (a Windows PC and a Mac), and Claude makes most of the commits.

- At the start of every session, before reading or editing anything, run `git pull` and resolve anything it reports.
- Pull again right before committing, then push so the other machine can pick the changes up.
